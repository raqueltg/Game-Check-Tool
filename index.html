How to complete the checklist

For each listed element, indicate whether it is present. The original Game-check asks researchers to check all applicable elements. In this digital version, each element has an individual response and optional notes.

Using the Game-check prototype

Complete the descriptive questions, then assess the listed elements under money, time and attention/engagement. Select one response per item: Yes, No or Unclear. Use the separate Further information button whenever you want to add an explanation, evidence or researcher notes.

The original tool notes that pressure strategies are not necessarily negative and that strategies may cover multiple domains. Some items are wellbeing supportive measures and are reported separately.

Response meanings

  • Yes: the element was identified.
  • No: the element was not identified.
  • Unclear: available information is insufficient to determine whether the element is present.

All data is stored in this browser on this computer. Export JSON regularly as a backup. This prototype has no server or user accounts.

Important: Replace the illustrative questions and configure defensible classification rules before using the tool for actual research.
